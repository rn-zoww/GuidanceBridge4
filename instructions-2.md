Create a dynamic, fully responsive website called GuidanceBridge with the following specification. 
# 1. CONTEXT - Target users: students experiencing bullying and negative peer influence. - Problem: fear of retaliation, public embarrassment and stigma stop students from using physical guidance offices or drop-boxes. - Solution: a web and mobile-responsive bridge that connects students to school guidance counselors safely and anonymously. 

# 2. SCOPE & GUARDRAILS - In scope: AI coping advice, severity assessment, intake routing, appointment scheduling. - Out of scope: deep therapy, replacing counselors, formal investigations, determining guilt, accusing individuals, supporting retaliation, collecting reports for disciplinary judging. - High-severity cases must immediately route to a human counselor. 

# 3. MUST-HAVE FEATURES 1. AI Intake Chatbot - The bot must reply automatically inside the chat window, streaming the answer as it is generated. It must NEVER redirect the student to another page instead of answering. A redirect or button to the appointment form is allowed only as the error fallback in section 4. - Gives immediate coping strategies within the guardrails. - Flags each case as HIGH or LOW priority. - After the AI reply, offers a choice: (a) a scheduled face-to-face appointment or (b) an anonymous private chat with a counselor. - Available on a dedicated /chat page AND as a persistent floating maroon pill button, bottom-right on every page except /chat, labeled "Talk to us ↗", with a small gold circle star icon on its left. 2. Face-to-Face Appointment Form (/appointment) - Fields: student information (name optional, alias allowed), grade/section (optional), case severity (Low / High), preferred dates/times (required), notes (optional). - Submits directly to the counselor dashboard. 3. Every link and button must point to a route that actually exists. No dead links, no 404 pages. Unknown URLs fall back to the home page. 

# 4. AI INTEGRATION (GROQ) - Provider: Groq (OpenAI-compatible API). - Endpoint: https://api.groq.com/openai/v1/chat/completions - Model: openai/gpt-oss-120b (a reasoning model). - API key: read from the server-side environment variable GROQ_API_KEY (placeholder value: YOUR_GROQ_API_KEY_HERE). NEVER expose the key in client-side code. All chat calls must go through a backend route (POST /api/chat) that attaches the key and forwards the request. The backend must actually run (for example Node/Express, or a Next.js route handler at app/api/chat/route.js). Do not build a static-only site. - Parameters: temperature 0.4, max_tokens 600, reasoning_effort "low" (required, otherwise reasoning tokens use up the token limit and the reply comes back empty), stream: true. - Stream the response to the browser and render it live in the chat bubble. - Send the full conversation history on each request, with the system prompt below as the first message (added by the backend). - Error handling: on any failure (missing key, network error, empty reply), log the real error on the server, and show the calm fallback message in the chat: "I'm having trouble connecting. You can still request a counselor meeting." plus a button to /appointment. Warn in the server console at startup if GROQ_API_KEY is missing or still the placeholder. - Severity flag: instruct the model to end every reply with a machine-readable line, "SEVERITY: HIGH" or "SEVERITY: LOW". Hide this line while streaming, strip it before display, and save it with the intake record so the counselor dashboard can sort by it. 
A case stays HIGH once flagged HIGH. - Add a client-side check for crisis language (self-harm, abuse, immediate danger). If it triggers, skip the AI reply, mark the case HIGH, save the intake, and show an urgent message with counselor contact options and a local crisis hotline (use a clearly marked placeholder to verify before launch). 

SYSTEM PROMPT (use exactly, then append the one formatting line after it): "You are the GuidanceBridge AI Assistant for students. Your job is to provide supportive, immediate coping advice for peer pressure and bullying. STRICT GUARDRAILS: 
1. NEVER identify, accuse, or determine the guilt of any individual. 
2. NEVER conduct clinical therapy or replace human guidance counselors. 
3. Keep advice focused on immediate emotional safety and coping mechanisms. 
4. Always evaluate if the case is HIGH or LOW severity. 
5. Conclude by offering to schedule a face-to-face appointment or an anonymous private chat with a counselor. Use a warm, calm, non-judgmental tone with short paragraphs. If the student mentions self-harm, abuse, or immediate danger, mark the case HIGH and urge them to contact a counselor or trusted adult right away." Appended line: "Format rule: end every reply with one final machine-readable line, exactly "SEVERITY: HIGH" or "SEVERITY: LOW"."
